# Custom assets

Place your own media files in this directory before building. The repository
does not include the author's private artwork or video.

Required filenames:

- `wallpaper.mp4`
- `sidebar.jpg`
- `input-card.png`
- `brand-logo.png`
- `new-session.png`
- `collapse.png`
- `search.png`
- `filter.png`
- `add-workspace.png`
- `settings-16@2x.png`
- `settings-18@2x.png`

Use real transparent PNG files for logos and button artwork. A checkerboard
drawn into an RGB image is not transparency.
